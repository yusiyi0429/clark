# 表达规范与字数

目标：负责人很快看懂、很快做判断。参照航空业的简化技术写作规范（ASD-STE100）：一句一事，句子短，用统一的词，先说结论。先在 analysis 里想清楚，再按本页写给人看；分析过程、评分和检查清单不进正文。

## 写法

0. **人一看就懂。** 原则是简单、直白、精炼、准确。这一条管所有给人看的字：标题、成果、验收、风险、依赖、取舍、边界、里程碑、Task 的成果和验收、停止条件，一个都不例外。本技能自己用的术语只用来想清楚，不写进正文，比如“场景检验”“真实运行档”“供给”“跨域”“前置”“scope”“承接”；要写就换成人话，比如“场景检验”改成“在 3 个真实问题上试用通过”，“跨域冲突”改成“和谁的哪件事抢人或抢时间”。验收写成“怎么一眼看出做到了”：谁、在哪里、做了什么、留下了什么记录。写看得见的事：谁、做了什么、做完能看到什么。不用要人再翻译的抽象说法，比如“××状态”“××入口”“可供××”“具备××”“可决策”“可用于××”“支撑××”“承接”“打通”“闭环”“赋能”。**写确定的话。** 写下来的成果和验收都是要做成的事，不写“争取”“有余力时”“尽量”“视情况”“力争”“条件允许时”这类有条件或含糊的说法，也不在正文里写档位。真有前提或风险，写进风险或依赖。例如“CEO 与 DRI 争取连续两周用天枢办经营工作；多人协作有余力时进入两轮使用”改成成果“CEO 和 2 名 DRI 连续两周用天枢办经营工作”，风险里写“DRI 10/20 前排不出时间，就先由 CEO 单独用，第二周再加人”。写完问一句：没参与讨论的人读一遍，能不能马上说出具体发生了什么、怎么看出来？说不出就改。例如“集团经营问题进入可决策状态”改成“王总能就至少 1 项真实经营问题，在给出的选项里做出选择”；“正式经营入口可供使用”改成写清王总在哪个产品里、用它做哪件事。
1. **一句只讲一件事，句子要完整。** 一句话不超过 30 个字，超了就拆成两句；每句有主语和动词，不写电报式的词组堆叠。
2. **先说结论。** 每个字段第一句就是答案，原因和条件放后面。
3. **主动句，写明谁做什么。** “王创峰 10/20 交付限流接口”，不写“限流接口将被交付”。
4. **用统一的词。** 同一个东西全文用同一个叫法。专有名词第一次出现时写全称或用半句话解释；不用只有作者懂的缩写、代号和自造词，比如“本线”“××线”，直接写 Mission 的名字或“本 Mission”。“真实”只在需要和演示、模拟区分时用，不当修饰词到处加。
5. **要点格式**：多项内容写成要点，每个要点是“**短标题：**正文”，短标题点明主题，正文不加粗。一个要点只讲一件事，宁可少写几条，也不在一条里塞进四五件事。
6. **标题**：一句话说清做成什么，写明对象和做成后的状态，读的人不看正文也知道要做成什么。一般 12–20 字。不写成“让……”“完成……”，不加日期或领域前缀。
7. **标注放对地方**：“推断”“待确认”“建议”等标注写在约束与依赖里，不放在标题、成果和里程碑里。负责人写了名字就是建议人选，旁边不再写“待核”。
8. **同一件事只写一次。** 上层写过的前提、条件、完成定义，下层不照抄；需要时用半句引用。“不以模拟替代”“演示不算”这类话只在 PO 的完成定义里出现。
9. **握手清单写在一处。** 需要谁在什么时候核对、确认、决定的事项，在单元计划的依赖里列成一张清单（谁、确认什么、哪天），Mission 和 Task 不再各写一遍“某日核对”。
10. **具体代替空话。** 不用“形成闭环”“已明确”“具备条件”“做好”“合理”。写数字、阈值、名单、日期。未知项写在受影响的内容旁边，说明缺什么、影响什么。

## 字段字数上限

上限不是写满的目标。用户明确指定其他上限时按用户的。

| 内容 | 上限 |
|---|---:|
| Card短标题、分点短标题 | Card标题20字；分点短标题12字 |
| 成果描述／工作结果／预期产出 | 每字段100字 |
| 存在必要性、责任边界、核心路径、关键取舍、约束与依赖 | 每字段合计150字，每点50字 |
| 验收标准 | 每字段合计200字，每点50字，最多5点 |
| 上级Plan中的下级成果摘要 | 每个下级50字 |

本技能的字段和上表的对应：贡献对应“存在必要性”，范围与边界对应“责任边界”，实现路径和 Mission 计划对应“核心路径”，取舍对应“关键取舍”，依赖、风险、停止条件对应“约束与依赖”，成功标准和完成定义对应“验收标准”。

每个里程碑和关口写成“MM/DD 结果标签”：一个日期，空一格，再写不超过 10 字的结果状态（如“10/23 首次真实调用”）。不写日期范围、“前／后”或括号备注。

计数按去掉格式标记、序号和空白后的可见字符，汉字、字母、数字、标点各算一个。超长时先删重复和空话，再改短句；不删范围、阈值、责任、日期和关键风险。

## 交付前自查

- 只看标题和成果，能说出要做成的具体事情吗？
- 每句话是否只讲一件事、不超过 30 字？
- 有没有只有作者懂的词？
- 同一件事有没有在上下层写了两遍？
