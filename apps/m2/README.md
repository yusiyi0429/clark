# M2 目标拆解与协作

从 2026-10-14 的 M2 demo 固定代码和技能，作为独立服务接到天枢。旧版首页提供“目标拆解与协作”，新标签页打开同站点 `/m2/`。本轮只验证独立分解与领域内讨论、修订和确认。

M2 每次请求向旧版 `/api/auth/session` 核对 Cookie。签名、到期、账号凭据版本和人员身份由旧版检查。M2 再用部署配置中的稳定 personId 映射自己的成员及职责；浏览器自报的成员编号会被覆盖。未登录、失效、未加入名单和跨站写请求均拒绝。M2 不能直接继承旧版工作台视角为业务确认权。

## 数据和版本

当前团队计划、旧轮归档、讨论、私聊与签名通过私有 bootstrap 文件交接，运行后写入独立 `m2_state` 卷。真实 bootstrap、账号映射、来源清单、模型密钥及产品只读凭证不进入 Git 或镜像。旧版数据库不新增迁移，也不同步或覆盖旧版计划。导入当前状态不重新生成或重写模型输出。

技能包随代码固定。新轮读取当前部署的技能并保存快照；历史轮使用自己的来源和技能标识。源代码文件哈希见 source-manifest.json；集成适配修改过的文件可与原 demo 对照。

服务器使用独立产品只读凭证读取本体，保留原来的筛选和来源指纹校验。没有凭证时新轮按钮不可用，已有计划仍能阅读与协作。不会读取个人 Codex 凭据。Codex 读取桥仅保留为显式启用的非生产开发方式。知识库重开依赖飞书 CLI，在这个服务器镜像中未配置，不作为本轮入口。

## 验证

- `pnpm --filter @warmap/m2 test`：可移植的领域回归以及真实 HTTP 登录、越权、数据范围、私聊和双签检查；不调用真实模型。
- `pnpm --filter @warmap/m2 build`：独立 Vite 构建。
- 原 demo 的历史轮次和浏览器测试仍在原工作区运行；其真实发布样本、个人机器路径未放入 CI。
- 本地启动、上线流程与限制见[试用指南](../../docs/guides/m2-trial.md)。配置统一保存在根目录 `.env`，规则见[环境指南](../../docs/guides/environment.md)。

已知边界：九成员和十个 RU 为当前配置；单进程文件存储；跨 RU 联合修改、旧版会议／洞察联动及正式本体写回不在此次范围。技术通过不表示分解业务质量已经验收。
