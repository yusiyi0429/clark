# 任务卡本人审核整合

Status: resolved
日期：2026-09-30
基础分支：feat/mvp-member-workspace
参考分支：feat/mission-card-self-review

## 用户已确定的范围

保留当前主分支的正文批注、引用到右侧私聊、Agent 即时改写、澄清问题与选项、批注原文和修改历史、规范起草、正式字段，以及五页首次观看案例引导。移植另一分支的本人完成审核／取消确认、全员完成自动汇总、页头切人和状态显示，不整体合并旧分支或采用另一套批注工具。

仅在下发审核后、本人的卡尚未完成审核时即时改写。完成审核前必须处理完待改批注；不能处理的批注允许本人明确保留备注、暂不修改，并记录原因。汇总后修改正文需要重新开放审核。已确认任务的正式更正路径保留。

## 完成条件

- 本人才能完成或取消自己的审核，验证所读任务版本；全员按该战场本月任务卡的负责人计数。
- 最后一人完成审核与汇总快照在同一事务内提交；重复请求、并发请求不生成重复快照。拍板人仍可提前汇总，页面说明尚未完成审核的人员。
- 待改批注阻止完成审核和手动汇总；重新开放清空本人确认；旧审核期间生成的候选不能跨重新开放写回。
- 原建议与当前字段不符时禁止采纳，防止覆盖即时改写后的正文。
- 页头采用统一 48px 二级页面布局：标题旁的状态与切人菜单，右侧审核操作、任务视图菜单和淡问号。正文不再显示人员页签或常驻流程卡。
- 审核期间只显示蓝色「审核中」与绿色对号「已完成审核」；手机 320／390px 保持操作可达且不溢出。
- 五页案例引导同步审核流程，仍使用与开启执行事项共用的翻页动效和首次完整观看标记。
- 迁移使用 053，现有 048–052 保持原样；测试仅使用隔离随机测试库，所有业务读取继续通过 API。

## 验证方式

相关 API 集成测试、Web 行为测试和类型检查；隔离浏览器验证本人确认／取消、切人、提前汇总提醒、批注改写与留痕、未处理批注出口、全员自动汇总、重新开放及首次引导；检查桌面和手机布局与控制台错误。
