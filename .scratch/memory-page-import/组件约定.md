# 记忆导入确认组件：用法约定（给上手流程接「导入的记忆」标签）

分支 `feat/memory-page-import`。组件在 `apps/web/src/components/memory/`。

## 1. 两个组件

| 组件 | 文件 | 做什么 |
|---|---|---|
| `MemoryImportReview` | `MemoryImportReview.tsx` | 一次导入的五步进度、两组要本人看的（有冲突、没把握）、其余各组折成数字、「确认导入 N」 |
| `MemoryImportPanel` | `MemoryImportPanel.tsx` | 新建一次导入：ChatGPT / Claude 切换、粘贴框、Claude 的上传、「复制提示词」 |

「我的记忆」页的导入弹窗就是这两个拼起来的（`MemoryScreen.tsx` 里的 `ImportDialogBody`），上手流程照同样的方式拼。

## 2. `MemoryImportReview`

```tsx
<MemoryImportReview
  importId={id}                    // 必填：POST /api/me/memory/imports 返回的 id
  onConfirmed={(result) => ...}    // 可选：确认成功后调用，result.counts.imported 是导入了几条
  onDiscarded={() => ...}          // 可选：给了才出现「丢弃」（按两次），丢弃成功后调用
  className="..."                  // 可选
/>
```

- 自己读 `GET /api/me/memory/imports/:id`，处理中每秒刷新一次，停在「等你确认」后不再刷新。
- 状态（根节点 `data-import-status`）：
  - `processing`：只有步骤列表；
  - `awaiting_review`：步骤列表 + 有冲突 + 没把握 + 折叠数字 + 「确认导入 N」；
  - `failed`：步骤列表（停住的那一步）+「重试」；
  - `confirmed`：步骤列表（最后一步「导入 N」打勾）+ 完成行。
- 默认值：
  - 冲突默认「保留旧的」，没把握的默认不勾；
  - 把握大的个人偏好默认勾上，在折叠的「导入 N」里，可以展开取消；
  - 把握大的公司事实也默认勾上，在折叠的「公司 勾上/一共」里，可以展开改勾选。
- 公司事实（10/18 用户定）：V1 当本人记忆导入，只有本人能看。
  - 存进「想法与立场」组（kind `idea`），钉 `topic:公司事实`。
  - 候选上的分类仍是 `company_fact`。10/30 第二版做「管理员确认后转公司知识」时，按这两处找出来迁移。
- 同一个 `importId` 重新挂载时会重新读一遍，组件里的勾选不保留（确认前离开页面，下次回来按服务端默认值重来）。

### 上手流程最后一页的接法

上手流程一般会有两次以上导入（ChatGPT、Claude 是用户粘贴或上传的；Claude Code、Codex 是采集器在后台上报的），按下面接：

1. 用 `GET /api/me/memory/imports` 拿本人最近 20 次导入，取 `status` 是 `processing`、`awaiting_review`、`failed` 的。
2. 每一次导入放一个 `MemoryImportReview`（可以上下排，也可以像「我的记忆」页那样一排切换）。
3. 每个组件的 `onConfirmed` 回来后记一下；全部确认过（或列表为空）时，把「导入的记忆」标签打勾。
4. 第三步扫描还没跑完时，采集器的导入可能还没到：在标签里重新拉一次第 1 步的列表即可，组件本身不用改。
5. 「新导入」按钮放 `MemoryImportPanel`，`onCreated(created)` 回来后把 `created.id` 加进第 2 步的列表。

## 3. `MemoryImportPanel`

```tsx
<MemoryImportPanel onCreated={(created) => ...} />   // created 是 MemoryImport（id、status、steps）
```

- ChatGPT：只能粘贴（ChatGPT 的记忆没有导出）。Claude：粘贴，或上传 `.zip`（导出包，按 base64 发）、`.json`、`.md`、`.txt`，也能拖进粘贴框。
- 粘贴框上限 64k 字，超过时字数变红、不能提交。
- 「复制提示词」把 `MEMORY_EXPORT_PROMPT`（`memoryModel.ts`）放进剪贴板；旁边的箭头展开原文。这是界面上唯一的引导文字，平时折叠。
- 旁边的「ChatGPT ↗ / Claude ↗」在新标签页打开对应产品。

## 4. 用到的接口

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/api/me/memory/imports` | 新建（202）。请求体 `{source, files:[{path, content, sha256, mtime, encoding?}]}`；登录态或 collector 个人令牌 |
| GET | `/api/me/memory/imports` | 本人最近 20 次 |
| GET | `/api/me/memory/imports/:id` | 步骤、计数、全部候选 |
| POST | `/api/me/memory/imports/:id/confirm` | `{checked:[候选 id], resolutions:[{id, choice: keep_old \| use_new \| neither}]}` |
| POST | `/api/me/memory/imports/:id/retry` | 停住时从那一步接着做 |
| DELETE | `/api/me/memory/imports/:id` | 确认前丢弃（204） |

采集器上报本机文件：`Authorization: Bearer <collector 令牌>`，本人要先在上手流程里同意采集（`PUT /api/me/collector/consent`），否则 403 `COLLECTOR_CONSENT_REQUIRED`。`source` 用 `claude_code` 或 `codex`，`path` 写本机真实路径（服务端靠路径认出项目记忆、全局说明、worktree 副本）。

## 5. 不要做的

- 组件外不要再写说明句子；状态靠步骤、数字和打勾。
- 不要绕过组件直接把候选写进个人记忆：确认只走 `confirm`，冲突处理和出处都在服务端做。
