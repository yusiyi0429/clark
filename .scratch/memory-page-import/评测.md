## 数据

- 文件：`h12/dataset.json`。全部是虚构的（人物「周子川」，公司「启明数智」），没有用任何人本机的真实记忆原文。
- 规模：107 条，来自 48 份文档；另有 12 条「已有记忆」，用来测重复和冲突。

| 来源 | 条数 |
|---|---|
| Claude Code（自动记忆，加 CLAUDE.md，含一份逐字相同的 worktree 副本） | 60 |
| Codex（AGENTS.md） | 6 |
| ChatGPT（已保存记忆、自定义指令） | 24 |
| Claude（提示词输出，五个字段） | 17 |

| 标准类别 | 条数 |
|---|---|
| 个人偏好 | 37（其中 24 条标了「默认勾选」） |
| 公司事实 | 16 |
| 只对某个项目有效 | 20 |
| 不导入 | 34（过期进度 19、一次性 5、私人生活 3、密钥 3、别人的信息 2、注入 2） |

- 对抗条目 12 条：注入、密钥、别人的隐私、和已有记忆冲突、换了说法的重复。
- 按源文件七三分开发集（76 条）和测试集（31 条），阈值只在开发集上看。

## 怎么跑

```
pnpm --filter @warmap/api exec tsx scripts/memory-import-eval.ts --env <主工作区 apps/api/.env> --runs 3
```

- 跑的是产品里同一套函数：拆分 → 分类 → 去重和冲突 → 定默认勾选（`apps/api/src/memoryImport.ts`、`memoryImportAgent.ts`）。
- 模型：`gpt-5.6-terra`（LIGHT_MODEL），不开思考。可以用 `MEMORY_IMPORT_MODEL` 单独换。
- 不开 LangSmith，不打印密钥。
- 粘贴的文档改用 `paste-<n>.txt` 当文件名，和网页里一样，不让文件名透露「这是自定义指令」。
- 每次跑完，结果写在 `h12/results.json`：逐条的预测、分组和阈值扫描。

## 阈值

默认勾选的阈值是 0.85。开发集上扫了一遍（三次的「默认勾选数 / 其中错的」）：

| 阈值 | 第 1 次 | 第 2 次 | 第 3 次 |
|---|---|---|---|
| 0.75 | 16 / 1 | 17 / 2 | 17 / 2 |
| 0.80 | 14 / 0 | 15 / 1 | 11 / 1 |
| **0.85** | **12 / 0** | **10 / 0** | **6 / 0** |
| 0.90 | 6 / 0 | 7 / 0 | 6 / 0 |

0.85 是三次都不出错的最低一档。

## 调过的两处

1. **提示词。** 第一次调整后，自定义指令这类第一人称的要求被压到了 0.8 左右，默认勾选只剩 1 条。改法是在提示词里写明：第一人称、对 AI 提的通用要求算本人明确提出的；第三人称的「偏好…」是转述。
   - 提示词里的例子都另写，没有用评测集里的句子。
2. **项目级说明文件不默认勾选。** 第二次调整后错了 1 条（6.3%）：项目 CLAUDE.md 里的「拿不准接口怎么用时先问我」，「接口」可能只指这个仓库。
   - 改成：项目级说明文件里的个人偏好一律送「没把握」，请本人看。依据是导入设计 4.5「在个人偏好和项目指令之间摇摆的」。
   - 全局说明（`~/.claude/CLAUDE.md`、`~/.codex/AGENTS.md`）和 Claude Code 的 feedback 记忆不受影响。

## 错在哪

- 分类错的只有两条，都是「做法」被分成了项目指令：「测试只跑相关用例」「命名用完整单词」。这两条出自项目记忆，标注时也注明了范围存疑。
- 默认勾选三次都是 0 错。代价是召回不稳：该勾的 24 条，三次分别勾上 75%、63%、46%。漏掉的大多是 Claude Code 的 feedback 记忆，模型给了 0.75–0.84。
  - 其中一部分进了「没把握」请本人看；超出 15% 上限的进了「未导入」，在折叠组里可以补勾。

## 局限

- **数据是虚构的。** 评测集是另一个 Agent 按这次的类别定义写的，和真实记忆的口吻、长度会有差距。门槛过了，只能说明流水线在「像真的」数据上可用。
  - 设计里要求用你本机的真实记忆、由你盲标再测一次，这次没做，因为任务要求不用真实原文。
- **「要本人看的 ≤ 15%」是上限保证的。** 每次导入最多请本人看 15% 的条目（最多 15 条），这一项一定能过。真正要看的是：被挤到「未导入」的条目里，有没有本该导入的。三次里有 2–6 条。
- **只按整批算。** 按测试集单独算，负担是 16.1%：15% 的上限是按一次导入整批算的，测试集不是一个独立的批次。
- **同一次评测里各次结果有波动。** 默认勾选数在 11 到 18 之间，原因是模型给的把握有波动。
- **预览库里做了一次端到端的真实导入：**
  - 41 条，拆分加分类约 20 秒，停在「等你确认」，有 6 条请本人看；
  - 粘贴的自定义指令没有来源线索，大部分只给到 0.78–0.82。修改提示词以后，评测里这类条目能到 0.89–0.94，但在这份预览数据上，修改后的提示词没有再跑一遍。
