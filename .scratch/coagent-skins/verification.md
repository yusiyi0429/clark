## 验证边界与发现

- 内置浏览器的真实麦克风权限请求无法完成，因此录音使用隔离页面提供的合成音频流；真实 MediaRecorder、音量分析、上传和会议界面照常运行。云端转码/识别也使用隔离 fixture 返回值。没有验证物理麦克风和云服务。
- 系统级 prefers-reduced-motion 未实际切换；对应 CSS 已核对，页面覆盖分支已实测。
- 三款皮肤的切换和两种姿势已检查，但没有把每一款在两种尺寸的所有录音/入群步骤都独立重复一遍。
- 控制台仍有 React Aria 的 PressResponder 警告；早期验证页在 hydration 前写入属性导致的一次 hydration 错误已从临时验证页修正，之后未再出现。完整记录在 `evidence/console-warnings.json`。
- 录音期间邀请成员会更新会议版本，第一次结束会议出现版本冲突提示；录音已停止、胶囊已消失，使用最新页面状态再次结束成功。这是会议并发操作的现有路径，本次未修改它。
