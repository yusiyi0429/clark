## 已发现并修正的反例

1. 无关回复到达抢焦点 → 成功定位记忆及明确导航重置。
2. 头部安排展开无限增长 → 只对安排正文限高滚动。
3. 不同时间偏移的ISO文本排序颠倒 → 按实际时刻稳定排序。
4. 待确认会议主操作只看正文 → 引导到会议处理事项，保留次级读记录。
5. 输入框样式不符既有规范 → 使用共享field变量及边框/光晕，不手动缩放文本域。
6. 时间线分桶变化重挂交接卡、丢失未提交说明 → 独立事件与消息改为同层keyed列表，5个实际元素树用例验证父级/类型/key路径保持；真实表单生命周期仍待浏览器观察，见fix-timeline-state.md与re-review-final.md。
