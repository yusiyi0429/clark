## 修订（2026-09-28，用户确认）：手持 / 工作台两种模式

用户要求 CEO 的单屏、双屏不要拥挤，只留真正需要的内容，体验链路由 Claude 设计；两项取舍都选了推荐项。

**模式**
- **手持（≤959）**：单屏、双屏、三屏竖放。首页是一条滚动，内容列最宽约 600、居中，依次是：
  - 待你处理（通知，原样保留）
  - 精简「公司全局」：战场一行一个（编号、名称、负责人、N 待决策）；雷达一行（未读数）；公司级战略议题和公司能力只在有待决策议题时出现
  - 个人菜单

  详情铺满屏幕，左上角返回，底部问 Agent。
- **工作台（≥960）**：三屏横放、平板横放、桌面。通知栏 + 战场卡看板；详情带窄条和右侧 Agent 列（保持展开）。

**手持模式砍掉**
- 战场翻转卡（六个月目标长文、进展示意环）
- 「待决策 / 进展」切换
- 空的战略议题大卡
- 雷达扫描动画卡
- 公司能力大卡
- 议题页大号会议时间块，改成一行

**对前面做法的影响**：600–959 原来是两栏，改成手持单列。布局模式类规则从 ≤599 挪到 ≤959；只跟窄宽有关的压缩规则（字号、内边距）仍留在 ≤599。

**更正（同日）**：战场详情的「进展」视角是真实数据（本月 Mission 列表、成功证据），不是示意；用户确认保留。手持模式只砍首页战场卡背面的示意环。
