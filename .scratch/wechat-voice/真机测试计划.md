# 真机测试计划：AU05 + 微信语音 + 天枢唤醒

配置说明见同目录《AU05与微信语音输入配置.md》。下面每步写「怎么做 → 应该看到什么」，哪步不对记下步号和现象。

## 测试环境（本机，已起好）

- **MVP**（新版首页 + 这次的改动）：<http://localhost:3800>，登录 `sunm` / `8989`。
- **Inception**（CEO 工作台）：<http://localhost:4320/demo/projects> → 「澄川 · 决策战况验收」→ 进入。只用来试唤醒，别在首演那场里发消息。
- 用你平时的 Chrome 打开，网页要在前台。
- 微信电脑版 4.1.8 以上，登录着。

## A. 不用 AU05，先确认网页这一侧

1. 首页点右下「输入文字」→ 输入条展开、对话层升起、光标在输入框里。
2. 按 Esc → 收起回「输入文字」。
3. 键盘按 `Ctrl+Shift+Space` → 同第 1 步。
4. Esc 收起，键盘**按住** `Ctrl+Win` 说一句话再松开 → 按下时输入框就展开、光标进去；松开后微信的字落在天枢输入框里。点「发送」→ 消息发出，天枢开始回答。
   - **这一步最关键**：它说明浏览器收得到微信的语音键。若输入框没展开、或字没进天枢，记下来，后面改用方案 B / C。
5. 输入框里打几个字（用微信输入法打拼音）：组词时按回车只上屏、不发送；上屏后回车发送；Shift+回车换行。和以前一样。

## B. 配上 AU05

6. 按配置说明的方案 A 配好语音键（`Ctrl+Win`）。在天枢首页**按住** AU05 语音键说话、松开 → 同第 4 步。
7. 若第 6 步不行：换方案 B（操作组合：`Ctrl+Shift+Space` → 延迟 150–200 ms → 微信免提键），按一下开始、说完再按一下结束 → 字进天枢输入框。
8. 若第 7 步也不行：换方案 C（两颗键）→ 先点唤醒键，再按住语音键说话 → 字进天枢输入框。

## C. 不该触发的时候不触发

9. MVP 打开「等回复」→「+ 新请求」，点进「请谁做什么」框，再按 AU05 → 光标留在「请谁做什么」，微信的字写进这个框，天枢输入条不动。
10. 首页点「约会议」打开面板，再按 AU05 → 输入条不展开（面板里的输入框照常能用微信语音）。
11. 光标已在天枢输入框里时再按 AU05 → 不跳、不清空，接着往里写。

## D. 二级页

12. MVP 打开「等回复」，先点右列右上的收起，再按 AU05 → 右列展开，光标进右列输入框（「与天枢讨论…」），发出去的是这一页的对话。
13. Inception 打开一个战场，按 AU05 → 打开全局对话（不是这一页的右列），光标进全局输入框。

## E. 其他

14. 手机或窄窗口打开首页：右下是「输入文字」，点了正常展开（手机上用手机微信键盘自带的语音键）。
15. 备用听写：展开输入框后点附件旁边的灰色小麦克风 → 天枢自己的听写照旧（红点、计时、声波，字边说边进框）；按 ✕ 或 Esc 恢复原文。收起时看不到这颗麦克风。
16. 如果有 Mac：`Control+Command` 不会唤醒；按方案 B 配。

测完告诉我哪几步不对，我按现象改。都通过后再推送、开 PR。
