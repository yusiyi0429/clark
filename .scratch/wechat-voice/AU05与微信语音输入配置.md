# AU05 + 微信语音输入：配置说明（天枢 MVP / Inception）

2026-10-23。分支：MVP `feat/wechat-voice-wake`，Inception `feat/wechat-voice-wake`（都未推送）。

## 分工

- **语音**：主要用微信（微信电脑版的语音输入，或微信输入法）。天枢自己的听写降成备用：输入框展开后，附件键旁边一个灰色小麦克风，收起时看不到。
- **天枢**：只负责「唤醒输入框」——展开输入条、把光标放进输入框末尾。
- **发送**：说完检查一下，点「发送」（或回车）。

## 天枢认的唤醒按键

| 按键 | 说明 |
| --- | --- |
| 按住微信语音键 `Ctrl+Win`（含免提 `Ctrl+Win+Shift`）约 0.3 秒 | 只在 Windows。微信会在系统层把 `Ctrl` 拦掉，浏览器只看得到 `Win`（10/23 用按键检测页实测），所以天枢认的是「单独按住 `Win` 0.3 秒」：按住说话时 0.3 秒后展开并聚焦，**不用另配组合动作**，也不拦这一下。`Win+E`、截图 `Win+Shift+S` 这类快捷键在 0.3 秒内就按了第二个键，单按 `Win` 开开始菜单在 0.3 秒内就松开了，都不触发。 |
| `Ctrl+Shift+Space` | Windows / macOS 都认（mac 上是 Control，不是 Command）。给组合动作或单独一颗键用。 |
| `F13` | 普通键盘没有这颗键，不会误触；能否在 Ulanzi Studio 里录进去要试。 |

规则：

- 光标在别的输入框里（会议编辑框、批注框、「请谁做什么」……）：不抢，微信的字写进那个框。
- 光标已经在输入条里：什么都不动。
- 有弹窗开着（确认框、约会议、更新说明、导览）：不动。
- 输入法正在组词、按住不放的自动重复：不算。
- 页面要在前台：浏览器在后台时，网页收不到按键。
- **MVP**：首页展开输入条并升起对话层；二级页展开右列（窄屏打开对话浮层），话题围绕这一页。CEO、成员都有。
- **Inception**：只在 CEO 工作台；不管在哪页都打开全局对话（二级页里改看全局对话），和之前的「一键唤醒全局对话」一致。

## 查到的事实

**Ulanzi AU05（Vibe Key）**（[官方软件教程](https://docs.ulanzistudio.com/vibekey/au05/)、[AU05-X 教程](https://docs.ulanzistudio.com/vibekey/au05-x/)、[Dial Mini 教程](https://docs.ulanzistudio.com/dialmini/software/)、[产品页](https://www.ulanzi.com/products/au05-vibe-key-ai-voice-input-keypad-i018)）

- 3 颗键 + 旋钮 + 麦克风，USB 接收器；Ulanzi Studio 支持 Windows 10+、macOS 12+。
- 按键动作：把「快捷键」插件拖到按键上；能录快捷键，分左右修饰键。另有「延迟」插件、「动作触发器」（单击 / 双击 / 长按分开配）和「操作组合」（一个动作里排几步）。
- 语音键：「按住说话，松开后发送或执行指令」。官方建议把语音键的快捷键改成第三方语音工具的快捷键，点名了微信输入法、Typeless。
- 可按前台应用自动切换预设（偏好设置 → 预设文件 → 自动跟随）。

**微信语音输入**（[网易 · 电脑版语音输入](https://www.163.com/dy/article/KLLVV01J05149PH8.html)、[新浪科技](https://finance.sina.com.cn/tech/roll/2026-02-13/doc-inhmrtii9014087.shtml)、[金舟软件](https://www.callmysoft.com/support/7841.html)、[网易 · 微信输入法 Mac 2.0](https://www.163.com/dy/article/KOPV5LOO0511E2VD.html)）

- 微信电脑版 4.1.8 起全量：Windows 按住 `Ctrl+Win` 说话、松开出字；`Ctrl+Win+Shift` 是免提连续说。可在微信「设置 → 快捷键」里改。能在浏览器等任意输入框里用。
- Mac：按住 `Fn`（微信输入法 Mac 2.0 起，设置里能改快捷键、有免提模式）。网页收不到 Fn 键，所以 Mac 上天枢认不出微信的语音键，要用下面的方案 B。

**还不确定、要真机试的**

1. AU05 语音键按住期间，是否一直按住所绑定的组合键（按住说话的透传）。
2. 「操作组合」能不能做到「先点一下 A，再按住 B」。
3. ~~Chrome 收不收得到 `Ctrl+Win`~~ 已实测（10/23–24，检测页记录）：微信把 `Ctrl` 拦掉，只放过 `Win`；而且在 `Win` 按下约 16 毫秒后、松开前各补发一个看不见的假按键（浏览器里是 `Unidentified`，keyCode 252），用来压住开始菜单。天枢认「按住 `Win` 0.3 秒」，并且不把这种说不出名字的键算作「按了别的键」。
4. 微信电脑版自带的语音输入和独立的「微信输入法」，快捷键可能不一样，以你电脑上的设置页为准。

## 推荐配置

### 方案 A（Windows，首选：不用组合动作）

1. 微信电脑版升到 4.1.8 以上，「设置 → 快捷键」里语音输入是 `Ctrl+Win`（默认就是）。
2. Ulanzi Studio 选中 AU05，把语音键（开始说话）的快捷键设成 `Ctrl+Win`。
3. 打开天枢，按住 AU05 语音键说话：约 0.3 秒后输入框展开、光标进去；微信开始听；松开后字落进输入框；检查后点「发送」。

### 方案 B（Mac，或方案 A 里天枢没展开）

在 Ulanzi Studio 给语音键配「操作组合」：

1. 快捷键 `Ctrl+Shift+Space`（mac 上 Control+Shift+Space）：唤醒天枢输入框；
2. 延迟 150–200 ms；
3. 快捷键：微信语音的免提键（Windows `Ctrl+Win+Shift`；mac 在微信输入法设置里给免提模式设一个键）。

说完再按一次免提键结束（以微信的提示为准），点「发送」。

### 方案 C（最稳的退路：两颗键）

- 一颗键设成 `Ctrl+Shift+Space`（或 `F13`）：唤醒输入框；
- 语音键设成微信的语音键（按住说话）。

先点唤醒键，再按住语音键说话。

## 为什么选这几颗键

- 不用：`Ctrl+Space`（Windows 中文输入法开关、mac 切换输入法）、`Alt+Space`（Windows 窗口菜单）、`Cmd+Space`（Spotlight）、`Ctrl+K` / `Ctrl+/` 这类浏览器和网页常用键。
- `Ctrl+Shift+Space`：Chrome、Windows、macOS 默认都不占用；Inception 之前已经在用，两边保持一致。
- 按住 `Win`：微信语音键里唯一能传到浏览器的一颗，按一下就同时完成「唤醒天枢 + 微信开始听」。要按住 0.3 秒才算，避开 `Win` 自己的快捷键和开始菜单。只在 Windows 上认：mac 上那颗是 Command，按住它是各种系统快捷键的前半截。

## 检查按键

同目录的 `key-test.html` 用 Chrome 打开，按什么键当场显示，能看出浏览器到底收到了哪几颗键。AU05 到了以后，用它看每颗键实际发出来的是什么。

## 天枢自己的听写

降成备用、存在感放低（10/23 定）：

- 首页输入条收起时只有「输入文字」；展开后左边是 [附件] [小麦克风]，都是无底色的灰色图标，听写中小麦克风变 ✕。
- 右列私聊输入条右下是 [附件] [小麦克风] [发送]；群聊输入条是 [小麦克风] [发送]。空着时发送钮是灰的。
- 唤醒键只唤醒输入框，不开天枢听写；Inception 月度计划逐段只留「对这一段提意见」（光标进输入框，不进听写）。
- 听写模块和服务端接口（火山 flash 识别）留着，真机测完再决定去留。
