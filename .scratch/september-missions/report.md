```bash
docker compose -f infra/docker-compose.yml --env-file infra/.env exec api pnpm --filter @warmap/api missions:import /repo/seed/imports/missions-2026-09.json --dry-run
docker compose -f infra/docker-compose.yml --env-file infra/.env exec api pnpm --filter @warmap/api missions:import /repo/seed/imports/missions-2026-09.json
```

- 先 `--dry-run`：只校验（契约、负责人、能力域 / 战场编号是否在生产注册表里），不写入。任何一条不合法，整批都不会写。

- 可以重复运行：已导入的会显示「已存在，跳过」。
- 现有 5 条战役级 Mission（01-1…01-4、02-1）不受影响，编号不冲突。
- 导入后核对：成员首页能看到自己的 9 月 Mission；月末复盘开启后个人复盘名单 = 这 7 人。
