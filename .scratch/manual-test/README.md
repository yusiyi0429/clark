# 时间机器测试环境

用来手动测试那些要等真实时间的流程：
- 本月 Mission Card 的 48 小时讨论、截止快照、集中 Review、确认、确认后更正、跨月只读；
- 反复重看首次登录引导。

每次启动都是一套全新的一次性测试库（54329 上的 `warmap_test_*`）和合成身份，关掉就删，不碰开发库 5432。

## 启动与关闭

在仓库根目录用 PowerShell 7：

```powershell
pwsh -NoProfile -File .scratch/manual-test/start.ps1   # 启动：API 4500 + 网页 3500
pwsh -NoProfile -File .scratch/manual-test/stop.ps1    # 关闭：删库、停网页、删副本
```

- 本机没有 54329 的测试库时（例如只开了 55432 的容器），启动前先设 `$env:TEST_PG_URL = 'postgres://postgres:postgres@localhost:55432/postgres'`。
- **电脑**：打开 `http://localhost:3500`。
- **手机**（和电脑同一个 Wi‑Fi）：先启动本机 HTTPS 反代（`pwsh -NoProfile -File .scratch/lan-https/start.ps1`），再打开 `https://192.168.124.44:8444`。登录要 https：会话 cookie 带 Secure，http 的局域网地址存不下。
- **第一次打开要编译**，等 10–30 秒。
- **网页是启动那一刻的代码副本**。改了代码要先 stop 再 start。
- **环境运行期间不要跑 pnpm 的全仓库命令**：副本 `apps/web-manual-preview` 会被当成第二个 `@warmap/web`。

### 王路遥能测什么

- 首次登录默认 CEO 引导；个人菜单「切换到 DRI 工作台」后能回到 DRI 工作台，也能切回 CEO。个人菜单「重看首次引导」会重置本人的看过记录并打开对应视角的引导。
- CEO 视角：首页产品战场（编号 03）的十月讨论轮次，倒计时初始约 36 小时；王路遥、周听澜、许知微、孙铭泽四张个人卡，每人两项填满字段的任务，五条字段意见包含评论、划词引用和修改建议。截止后意见进入待拍板处理。
- DRI 视角：原有团队协作已确定个人卡、灯塔项目参与记录、执行事项和个人雷达仍在；另能看到本人负责的产品战场及讨论中的个人卡。
- 个人计划里原有团队协作两组任务、五个步骤、带日期的里程碑及独立事项；步骤的等待关系、起止日期和无日期状态仍可查看。已确定的团队协作卡照常能拆成执行事项；产品战场的卡还在讨论，确定后才出现在计划里。
- 事项详情中的完成定义、判断、协作者、私人批注、两条演示进展、会后分派来源与原话；事项群组里的 Co-Agent 开场和成员发言。
- DRI 通知栏里的协作邀请、会后分派及未读雷达信号；个人雷达列表的已读和未读状态。CEO 视角的通知栏可进入产品战场四人卡。

## 拨钟与推进

在仓库根目录执行 `node .scratch/manual-test/control.cjs <命令>`：

| 命令 | 作用 |
|---|---|
| `inspect` | 打印当前应用时间、轮次、卡、意见、Review、更正与执行事项 |
| `draft` | 用 CEO 身份整理灯塔项目 10 月个人卡草稿（也可以在界面上点） |
| `open` | 统一开放 48 小时讨论（也可以在界面上点） |
| `near` | 把时钟拨到截止前 65 秒 |
| `advance` | 把时钟拨到截止，生成截止快照，进入集中 Review |
| `reopen` | 重新开启 48 小时 |
| `confirm` | 确认（要求所有意见都已处理） |
| `confirm-all` | 一步完成：整理 → 开放 → 截止 → 确认（没有意见时） |
| `next-month` | 把时钟拨到上海 11 月 1 日 10:00，10 月的卡变只读 |
| `welcome-member` | 重置孙铭泽的首次登录引导，下次登录会再走一遍 |
| `welcome-dri` | 重置林知行的首次登录引导 |
| `welcome-ceo` | 重置验收 CEO 的首次登录引导 |
| `welcome-luyao` | 重置王路遥的首次登录引导 |
| `material-edit` | 模拟「我的 Agent」按上传者的要求改最近上传的一份 Markdown：改写一段、删一个列表项、文末加一段；材料上出现修改标注，群里出现一条说明（时间机器的 Agent 不连模型） |
| `review-open` | 用 CEO 的「开始复盘」提前开启当月的月末复盘（平时月底倒数第 3 天自动开启）。打开 `/reviews/<当月>` 看总览；Method 能力域的负责人是孙铭泽（`browsermember`），其他待指派的项由 CEO 代复盘。三个复盘 Agent 给的是演示内容，会等两三秒 |
| `review-prefill` | 月底复盘第三版：替孙铭泽跑一次上个月的预评（时间机器不跑后台任务，没有模型，按条目序号给演示预评）。先 `next-month` 让 10 月进复盘，再打开 `/me/work/month/2026-10` |
| `target-none` / `target-negotiating` / `target-issued` | 本月目标的三种状态；只能在整理草稿之前用 |

时钟只往前拨，不能倒回。想从头来，stop 再 start。

- 语音转文字（输入框的麦克风 / 首页「点击说话」）：走真实的火山识别，密钥取自 `apps/api/.env` 的 `VOLC_ASR_*`（只取这几项）。用的是和会议录音同一个已开通的 2.0 模型，不用另外开通。
- 声纹：走真实的腾讯云声纹（凭据取自 `apps/api/.env`，只取声纹那几项），引导里有声纹那一步、个人菜单能录能删。测试身份的声纹注册在单独的分组 `tianshu_manual_test`，不进正式分组；stop 删库时不会顺带删腾讯那边的声纹。
- 雷达扫描：没有接外部检索；王路遥已有演示信号，可测设置、列表与阅读状态。手动刷新不会产生新的真实资讯。

- 想另起一套（不碰正在用的 3500 / 4500），启动 `server.ts` 前设 `TM_API_PORT`、`TM_WEB_PORT`、`TM_RUN_DIR`；`control.cjs` 也要带同样的 `TM_API_PORT` 和 `TM_RUN_DIR`。网页副本需要自己复制到别的目录（start.ps1 固定用 `apps/web-manual-preview`）。
