# 04b 本月 Mission Card：个人卡页与讨论

Type: feature
Status: ready-for-agent
Blocked by: 04a
Design: `../design-04-mission-cards.md` §3、§5、§6.1、§6.2、§6.6、§9（04b）
Spec: `../spec.md` §3（美学统一）、§6

## 目标

让 CEO 和成员都能打开个人卡页：
- 左侧看这张卡的 13 字段，在字段上评论、划词引用、提修改建议。
- 右侧在「事项群组」里讨论，或者在「我的 Agent」里私下问。
- 卡片上方「本轮」那一行说清楚走到哪一步、在等谁，拍板人在这里按「统一开放 48 小时讨论」。

## 范围

1. **接口**：卡页、意见、群组（分隔线、开场）、已读；以及 `mission-card:` 的对话 scope。设计 §5.1 里 04b 那几行，加上 §3.3。
2. **成员外壳 `apps/web/src/app/(member)/me/layout.tsx`**
   - 照 `(ceo)/layout.tsx` 和 CeoWorkspace 的结构做：左侧成员通知栏、展开区、ConversationHost，并提供 `WorkspaceContext`。
   - 成员首页 `/me` 的现有内容，改为这个外壳的主区。
   - 以后成员战场详情（03）、成员雷达页（02）都在这个展开区里打开。
   - 外壳的外观和交互跟 CEO 工作台保持一致：同样的展开和关闭过渡，关闭后回到来源，焦点还原。
3. **路由**
   - 成员：`/me/mission-cards/[cardId]`
   - CEO：`/mission-cards/[cardId]`
   - 两个入口共用 `MissionCardScreen`。
4. **前端组件**（移植清单见设计 §6.6）：`MissionCardScreen`、`CardDocument`、`RoundClock`，以及「本轮」那一行在 draft、open 两个阶段的部分。
   - **每月制定的规则在这里讲**：第一次打开时，「本轮」自动展开一次，写清五步各自的意思。引导里不再讲这些。
5. **ConversationHost 支持群组频道**：两个频道默认打开群组；输入条按阶段变化，引用小条可以取消；发送失败时放回输入；未读计数；每 3 秒轮询一次。
6. **占位标记**：版本行、每项个人任务的小标、开场里的那一句（设计 §7.4）。

## 质量标准

- 这一页是给几个人认真讨论承诺用的。正文要稳，版本要清楚，意见的处理要能追溯。
- 阅读宽度 760–880px。正文区接近不透明，只有页头和浮层用厚玻璃。截止时刻、负责人、来源都不能藏进小灰字。
- 美学与锁屏、引导、DRI 首页统一（spec §3）：圆角分三级；实心天枢蓝只用于行动和选中；动效克制，只由真实状态触发。
- 手机也要能读、能发意见，右列在手机上是浮层，不能横向溢出。CEO 主要用手机。
- 移植概念版时整页搬过来，数据换成接口；没搬的在报告里列出来（用户的长期要求）。
