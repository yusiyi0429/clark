## D：特异度根因

`app-shell.module.css` 的 `.shell button{cursor:pointer;color:inherit;text-align:left}` 特异度 (0,1,1)，
压过各 CSS Module 里 (0,1,0) 的裸类名按钮，导致 `color` 被强制回退为继承色。
改为 `:where(.shell) button{...}`（特异度 (0,0,1)），各模块自己的配色恢复生效。

回归检查（低对比文本按钮计数，综合 `background-color` 与 `color` 计算）：

| `/` | 10 | 0（唯一低对比项是禁用态发送图标，无文本） |
| `/issues/3d119c0a-…` | 10 | 0 |
| `/plans/2026-09` | 0 | 0 |
| `/radar` | 17 | 0 |

微文案下限统一为 11px、色值 `var(--ink-muted)` = `#63686f`（在 `#f6f6f8` 上约 5.2:1）。

## B/C：结构

- 主操作 `重新预审` 从栏底移到 Header 操作组，随页面常驻可见。
- Header 高度：1440×900 由 120px 降到 **77px**；1366×768 由 120px 降到 **70px**（≤879px 高度档）。
- 标题 `clamp(16px,1.15vw,19px)` 并限制两行；关联议题压成单行省略号，消除与 H1 的长文重复。
- 中央统一为「白底 + 左侧 3px 语义色条」，替换原先四种底色叠加。
- 左栏改为 预审结论（带标签）/ 最优先动作 / 最关键问题 / 四输入边界 / 评审目录。
- 评审目录 scroll-spy，且 `position:sticky;bottom:0`，任何高度都可见。

scroll-spy 实测（1920×1080，主列滚动 0 → 100%）：
`核心判断 → 材料体现出的积极信号 → 建议会议重点追问问题 → 一号位点评参考`。
点击「建议会议重点追问问题」后 `scrollTop` 到 1139，高亮同步切换到该项。
