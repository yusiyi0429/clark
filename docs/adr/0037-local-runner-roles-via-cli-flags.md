# 岗位进本机会话：用 Claude Code 自带的参数，文件放本机程序的数据目录

2026-11-06 决定。适用于 `apps/local` 拉起的 Claude Code 会话。依据：V2 设计第 19 节（岗位常驻、执行即弃），19.5 本机部分。

## 背景

长期存在、会成长的是岗位（职责、做法、验收口径、工具、模型档位，都是 Markdown）；每次开工把岗位带进 Claude Code，会话用完就丢。专题的评审会要并行请 2–3 个挑刺岗位，合成一份「分歧和建议」。要求：不往本人的仓库写任何文件。

## 实测（11/06，Claude Code 2.1.318）

先看 `claude --help`，再用假网关（能看到 Claude Code 发出的完整请求，不花钱）和真 haiku 各跑一遍：

| 参数 | 结果 |
|-|-|
| `--append-system-prompt-file <文件>` | 能用（`--help` 只在 `--bare` 说明里提到）。文件里的岗位正文原样出现在系统提示词里；不进命令行，避开 Windows 命令行长度上限 |
| `--agents <文件>` | `-p` 模式下可以给文件路径。定义的子 agent 出现在 Agent 工具的可选类型里（名字用 `critic-1` 这类英文，描述里写中文岗位名）；子 agent 的提示词只在调用它时才用 |
| `--plugin-dir <目录>` | 只在本会话生效。目录里 `skills/` 下放指向本人已装技能的目录链接（Windows junction）也认，显示为 `tianshu-feishu:lark-doc` 等 |
| `--system-prompt-snapshot` | 默认开：系统提示词在第一次请求时记下，续接时原样用。所以会话途中岗位改了，要新开一个会话才按新的来 |
| 真跑（haiku） | 带岗位的专题：提纲按岗位的做法只写了 3 条，存成第 1 版；正文第 2 版；点评审会后**同时**派出 critic-1（反方）、critic-2（读者视角），合成「分歧和建议」存成 kind = review 的第 3 版，正文没改。花费 $0.0096 |

真跑时还碰到一个毛病：Claude Code 在启动途中（握手回复之前）就连本会话 MCP，本机程序那时还没登记这个会话，第一次连接 401，它转去找 OAuth 又碰 403，整场会话都没有存版本的工具。已改为启动途中也认得这个会话的密钥（`sessions.ts` 的 `launching`），并用假 `claude` 在握手前连一次的测试锁住。

## 决定

- **岗位**：开工请求带 `role`（和云端交代里的 RoleBrief 同形）。本机把工作规矩（卡怎么交回、专题先交提纲、每改一次存一版）和岗位的职责、做法、验收口径、能用的工具写进 `<数据目录>/sessions/<id>/system.md`，用 `--append-system-prompt-file` 交给 Claude Code。没带岗位时只有工作规矩。
- **挑刺岗位**：专题开工请求带 `critics`（最多 3 个），本机写成 `agents.json`（`critic-1`…，只读：Read、Grep、Glob，名单里有联网搜索的再给天枢的 web_search），用 `--agents` 交给 Claude Code；主会话的系统提示词里列出它们。
- **评审会**：网页「说一句」带 `kind: "review"`，本机替本人说一句固定的话：同时调用这几个挑刺子 agent 读最新一版，合成「分歧和建议」，用 `save_version`（kind = review）存一版，不改正文。
- **工具名单决定挂什么**：
  - `tianshu` 或 `web_search` 在名单里（且关联了云端）才挂天枢 MCP；`web_search` 不在名单里就不给（`--disallowedTools WebSearch,mcp__tianshu__web_search`）。
  - `feishu`：本人装了 `lark-*` 技能时，本机在数据目录里建一个插件 `tianshu-feishu`，`skills/` 下是指向这些技能的目录链接，用 `--plugin-dir` 挂上；没装就在提示词里说明做不了。带个人配置的会话本来就有本人的技能，不另挂。
  - `github`、`browser`：没有可挂的插件，只在提示词里说明（`gh` 命令行照常要本人批准；浏览器先问本人）。
- 上面这些文件都在本机程序自己的数据目录里，**不往本人的仓库写任何文件**（测试断言工作目录没多文件）。
- 没有用的退路：「全部放进追加的系统提示词、让主会话按岗位提示起通用子 agent」。实测参数都能用，用不上。

## 代价

- 岗位改了，进行中的会话不变（系统提示词快照），下一个会话才生效。这和「改了下一张卡就按新的来」一致。
- 挑刺岗位在开工时定下；评审会途中换挑刺岗位要新开会话。
- 飞书插件是指向本人技能目录的链接，本人删掉或改了技能，下次开工时跟着变；链接只在本机程序的数据目录里，删它不碰本人的技能。
- 岗位正文原样进系统提示词，本机不审内容；岗位是本人在天枢里自己写、自己改的。
