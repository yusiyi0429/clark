## 3. 和本机程序的约定（D）

- 同步载荷以 `packages/contracts/src/localRunner.ts` 为准，接收端直接用它校验；D 改契约后合 `claude/local-runner-bd68bf`，跑 `localSync`、`workers`、`topics` 测试。
- 已切到 D 11/06 补的内容：`topic_version`、`topic_version_feishu`、`handback.outputKeys`、批次 `slots`、计划 `progress`、`queued` 状态。之前的临时做法（交出的 Markdown 当一版、交回算没被算过的全部产出）已删。
- 还缺：没有活的时候不报东西，设备 10 分钟没同步就算不在线（`ONLINE_WINDOW_MS`）。要更准需要本机发心跳（契约现在一批至少 1 条）。
- 「排第 n」是云端按这台电脑上 `queued` 会话的开工先后算的，和本机自己的 `queuePosition` 同一个规则；本机没报位置号，二者偶尔可能差一拍（同步还没到）。

## 4. 拿不准、留意的地方

- 专题撞号（两处同时写同一个专题）：云端把后到的排到最后，本机界面上的号会和云端不一样；飞书地址按本会话的本机号对回。
- 验收、拆卡、提岗位修改的队列在进程内；多实例部署前要换。
- `web_search` 的额度（每分钟 10、每天 200）是估的，按实际用量再调；并发时可能多出一两次。
- 预设岗位文件只有三份占位（`general/reviewer.md`、`general/opponent.md`、`strategy_content/researcher.md`），文件名就是预设的 key，测试按这三个 key 认，内容可以随便改。
- 交付物一版最多 10 份文件、5 个链接，出下一版超了直接报错，不自动挑。
- ADR 编号：本机程序分支的 0033（岗位进本机会话）和 V1 分支的 0033（约定存天枢）撞号，合并时要改一个；本分支用 0034–0036。
