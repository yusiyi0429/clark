# 本人个人资料

入口：个人菜单 → 设置 → 个人资料。CEO 和成员使用同一个本人入口。

- 姓名仍来自现有只读人员目录；不在资料表保存第二份身份。
- `gender` 是可选自填文字，最多 40 字。空白或 `null` 保存为 `NULL`，本人可随时清空。
- 没有预选值，不根据姓名、头像或其他资料推断，不回填现有人员。
- `GET /api/me/profile` 和 `PATCH /api/me/profile` 只按服务端登录身份取本人；没有读取或修改其他人资料的接口。
- 字段不加入公司人员目录、World、角色、MCP 或 Chat 上下文。可见范围为本人。
- 迁移 `211_personal_profile.sql` 新增本地 `person_profiles` 表。旧账号没有行时正常返回 `gender: null`，不需要回填。

这份修改只完成代码、迁移文件和本地验证。线上迁移与部署另行执行。
