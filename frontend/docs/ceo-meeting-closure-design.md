# 天枢 CEO Agent｜会前—会中—会后闭环设计

## 本轮边界

这一轮只实现 CEO Agent 需要直接感知的链路：同一议题进入会前阅读、会议录音、说话人核对、会议级核对稿，以及发布后的行动与 CEO 判断分流。持续调查、材料核验和材料变化由本体提供；执行追踪、完整 DRI 工作台与跨设备治理暂不实现。

## M1A / M1B 对齐

- Signal、Issue、Agreement 属于 M1A。会议不是新的议题对象，而是 Issue 形成 Agreement 的一种场景。
- LTCO、PCO、Mission 属于 M1B。CEO Agent 只引用确切的关联对象，不在会议纪要里复制目标正文，也不从一句行动自动创建 Mission。
- BusinessFact 独立保存；分析和会议摘要不能伪装成事实。
- 公开意见由本人发布；Agent 只起草。会后只有一份会议级核对稿，由主责 DRI 核对发布。
- 行动项按负责人分流；CEO 不确认整份纪要，只接收公司方向、跨域资源、外部承诺、重大风险和 Mission / Outcome 边界等少数判断。

## 交互原则

1. 会前阅读用于定向和建立结构，不设置“全部核对后才能开会”的门槛。
2. CEO 只做“阅、请补充、带到会议”三种轻动作，不在会前材料页选择方案。
3. 会议中保留议题判断和未知信息，主动作只有开始/结束录音。
4. 现有 ASR 只能做说话人分离，不能可靠识别人的身份。提炼前必须核对每个声源，并强制确认 CEO 声源。
5. 每条共识、行动、未决和 CEO 判断必须带可在逐字稿中逐字找到的原话。
6. DRI 发布后，行动项与 CEO 判断走两条路径；无负责人行动回到主责 DRI，不猜负责人。

## 当前实现与后续接口

- 已复用：浏览器录音、批量上传、火山转写、说话人分离、说话人改名、逐字稿存储。
- 已新增：会前阅读空间、说话人核对、会议级提炼契约、DRI 核对稿、行动/CEO 判断分流。
- 决定记录绑定录音与转写版本，并分别保留决定原话、依据、适用范围、关键假设和重新打开条件；其中任何字段没有原话就不采用。
- 暂为本机演练：阅读状态、核对稿发布和 CEO 确认记录。
- 后续由本体接入：Issue 与 Mission 的确切版本、材料变化、BusinessFact 来源、ReviewRecord 与真实发布权限。
- 后续由组织通道接入：行动项推送给对应 DRI、无负责人项推给主责 DRI、CEO 判断进入通知。

## 十点覆盖状态

1. **同一议题贯穿全程：本轮完成。** 会前、会中、会后均引用同一 `IssueId`；会议不是新的议题副本，决定和行动仍可回到原议题。
2. **内部信号进入天枢：未实现。** 依赖 M1A/M1B 与真实数据接入；本轮只完成覆盖检查，不制造新的信号入口。
3. **调查与证据：按要求不实现。** 持续调查暂缓，内部核验与材料变化由本体承担，不新增证据冲突或反对意见字段。
4. **会前阅读包：本轮完成。** 包含为什么现在、判断窗口、DRI、当前判断、未知、最近变化、关联 Mission 与会议。
5. **会前预审交互：本轮完成。** 使用“阅、请补充、带到会议”，不设置完成门槛，也不在阅读页确认决定。
6. **会中模式：本轮完成可运行链路。** 复用现有录音、上传、火山转写与声源分离；会议中始终保留相关议题上下文。
7. **会后决定记录：本轮完成原型链路。** 人工核对说话人和 CEO 后生成一份会议级核对稿，记录决定、原话、依据、范围、假设、复议条件、行动和未决，并按 DRI / CEO 两路分流。
8. **会后落实与重新判断：未实现。** 后续应由本体监听决定所绑定的假设和 BusinessFact；只有假设失效、执行偏离或风险越界时重新打开原 Issue，不能另建重复议题。
9. **DRI 与天枢协作：未实现。** 后续需要真实身份、发布权限和消息通道；主责 DRI 应拥有核对稿发布权，行动接收人只能接受、澄清或退回，不能改写会议原话。
10. **真实数据与跨设备连续性：未实现。** 后续应把阅读位置、ReviewRecord、发布记录和确认回执写入组织存储，按角色授权并保留审计；浏览器本地状态只能作为演练。

## 8–10 的建议接口

- `DecisionWatch`：绑定 `issueId`、决定版本、关键假设、失效条件和最新 BusinessFact，只在触发条件成立时生成重新判断请求。
- `OutcomePublication`：绑定会议核对稿版本、发布人、行动接收回执与 CEO 确认回执；消息通道只负责送达，天枢保留唯一事实源。
- `ReadingPosition`：按人员、设备和材料版本记录阅读位置；材料更新后保留旧位置，同时明确标出从哪个版本开始发生变化。
