## 阅读布局

- 仅调整全局历史深色面板；通知栏、议题双栏与会前预审工作区保留原有布局。
- 面板在主区两侧内收，顶部约留 10vh；继承原有 360ms 展开、250ms 收起动画。
- 正文居中，桌面最大 720px、大屏 800px。用户消息按内容宽度靠右显示气泡；助手正文不使用气泡，不重复显示姓名与“公司全局”。
- 保留天枢矢量标志；展开期间隐藏全局短句气泡。输入控制继续浮在最高层。

- 等待行独立刷新计时，显示实际后台阶段；停止或发送新问题后丢弃上一请求的迟到响应。

## 快速取证

`/api/warmap-chat` 使用已有 flash 配置。第一轮结构化回答决定直接回复或 `micro_research`；普通回答仍只有一次模型请求。

触发：用户要求查证外部事实，或某个关键外部信息缺口会改变当前判断。问候、内部状态、已有材料能回答的问题、明确不要联网时直接回复。检索式仅包含最小公共问题，不复制内部战略或客户安排。

实现复用 `talk/micro.ts → a4/evidence.ts` 的搜索、正文抓取、引用核对与共源折叠。聊天专用参数：一轮正反检索、最多三页、每页最多两条相关引句、整体取证 45 秒、单次抽取最多 25 秒。新增 `maxPages` 是可选项，旧调用默认仍为 8 页。

使用已有 Bocha / Doubao 搜索配置；不新增密钥，不写本体、议题或通知。来源仅来自通过既有台账校验的条目。无有效证据与服务不可用分别显示，不制造后台研究任务。

新客户端使用 NDJSON 获取 thinking / researching / answering 与最终回答；保留 JSON 响应兼容旧调用。来源可展开、打开原文。正文和来源均作为不可信内容渲染，Markdown 不启用原始 HTML。

旧搜索与抓取适配器仍使用各自的 HTTP 超时：停止会立即结束前台等待并阻止后续模型抽取；已经发出的底层请求可能持续到自身超时，但不会产生组织写入或插入迟到回复。

## 验证

- 断流、分片 UTF-8、JSON 兼容、直接回复、单轮取证、无证据、服务不可用、引用/口径保留与取消的自动检查。
- 既有取证、抓取名额与来源规则回归测试。
- 浏览器核对 1920 / 1440 / 1024 / 800 / 390 宽度，关闭/恢复气泡、停止迟到回答、正文留白、来源和用时。
- 真实接口：普通问候约 2 秒；一次 TypeScript 外部查证约 33 秒、两条第三方来源，回答明确非官方原文。一次 WCAG 取证未得到有效证据并如实显示。真实用时和命中率随服务与问题变化。


## 手动引用卡片（2026-09-11）

- 全局 `CardReferenceContext` 提供统一引用按钮和多选状态；通知、战场正反面、公司战略/能力、议题及重材料事项共享此机制。战役、普通雷达信号不提供引用按钮。相同对象跨位置显示时使用相同 ID，选择状态同步。
- 选中项在全局输入框内部以紧凑标签呈现，可看原文、逐个移除或清空。局部议题或材料工作区中的引用只加入全局草稿，不改变当前讨论范围；主动点击“在全局讨论”才切换到全局记录。
- 引用是注意力优先级，不是可信度提升、组织确认或任务提交。API 单独传入 `manualReferences`，包含标题、正文、来源、种类和采集时间；保留原有系统约束与来源边界。
- 活跃卡片发生变化时更新待发送引用；已发送消息保存独立快照。已处理的静态议题即使从首页移除，也更新引用中的决定状态。
- 当前支持同时引用 16 项，每项正文最多 8,000 字符、正文总计最多 64,000 字符；超出时明确提示，无静默截断。Radar 来源摘录沿用最多 3,000 字符摘要，不声称阅读全文。引用保留至主动移除或页面重载。
- 验证覆盖多选/取消/去重、通知按钮隔离、详情材料修改、已处理议题状态、引用预览与发送快照、四种屏宽；真实模型按引用材料回答并保留待批准与演练状态。

## 克制的交互调整（2026-09-12）

- 全局和当前议题分别保留输入草稿。未主动切换时，局部对话不会携带待发送的全局引用；全局记录不会误用被覆盖的预审或雷达材料作为当前讨论对象。
- 从议题进入全局引用讨论，先同步收起议题与移动输入区，再打开全局记录；快速切换会议或其他页面会取消旧转场的后续动作。
- 总结页和研究页只读呈现可带到会议讨论的备选路径，不提供点选、确认或撤回入口。老板在这里补足信息、形成判断；会议结论由参会 DRI 与天枢协同记录，若已回传则在议题页只读展示。
- 多行输入框的底部渐变只覆盖文字区，不再盖住发送按钮；发送按钮有内容时保持高对比主蓝色，无内容时才显示灰色禁用态。
- 本次以浏览器拦截回复验证引用发送范围、草稿、窗口转场和确认/撤回，未调用真实模型评估回答质量。源代码类型检查和修改文件的 ESLint 通过；仓库默认类型检查仍受历史构建目录引用已删除 schedule 页面影响。
