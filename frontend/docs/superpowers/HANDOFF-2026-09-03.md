## 5. 环境与工具的坑

### 5.1 起服务只能用 Browser pane，不能用 Bash

`.claude/launch.json` 里有一条 **`panel-check`**（端口 3013、独立 dist 与数据目录、
口令 `204060`）。用 `preview_start` 传 `{name: "panel-check"}`。
**不要改 `.claude/launch.json` 和 `tsconfig.json`** —— 它们此刻的 M 是别人的。

Browser pane 的标签页是跨会话共享的：**自己开一个 tab，每次调用都显式传 `tabId`**，
否则会落到别的 agent 的页面上（这事发生过好几次）。

### 5.2 `.next/dev/types/routes.d.ts` 是坏的

别的会话的 dev server 写了个截断的生成文件，`npx tsc --noEmit` 会卡在
`TS1128`。绕法：临时写一个 `extends ./tsconfig.json` 且 `exclude: [".next"]` 的
配置跑一遍，跑完删掉。`npx next typegen` 能几秒修好，但它会碰别人 dev server
正在用的目录，所以我没动。

### 5.3 看不到卡片是正常的

隔离数据目录是空的。要看到 action item，得走真链路开一场会、喂一份转写。
假模型只在 `TKOS_MODEL_MOCK=1` 时才用（本机没设，所以跑的是真模型，要花钱）。
真模型目前**不认第一人称**「我来做 X」—— 那正是相三 P1 要改的提示词。

### 5.4 语音那条线本机验不了

`.env.local` 里没有 `DASHSCOPE_API_KEY`。dock 的语音只是 UI 状态机，
故意没接 ASR，标签写的是「未接入语音识别」。这是设计，不是缺陷。

## 6. 这个仓库的规矩（别踩）

- **注释是交付物。** 中文、完整句子，说清「为什么是这样」和「上一版错在哪」，
  不复述代码在做什么。**一条变成假话的注释就是一个缺陷** —— 这轮已经因为这个
  开过好几次修复。
- **别造新词。** 用产品已有的词：一号位、秘书、座位、编排会议、纪要审阅、拍板。
- **每次有产出都要记账**：`src/lib/changelog.ts` + `package.json` 版本号同步，
  有测试盯着这一对。
- **不许编负责人。** 这是这条链路最坏的错：把一件事安到一个没接过它的人头上，
  屏幕上和真派过一模一样，而那个人根本不知道。`todo-assignee.ts` 整个存在就是为了防它。
- 提交信息结尾要带：
  `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`

## 7. 我替他做过的判断里，最该知道的几条

完整列表在各相的账本里。挑出会影响你决策的：

- **不开分支、不开 worktree，就在 main 的这个目录做。** 因为 `git checkout -b`
  会把同目录另外几个活会话一起拽走。代价：要回退得用 `git revert`。
- **「上传纪要 / 未召开」那两颗键留在一号位首页上。** 规格说会议全家归秘书，
  但 `/sec` 现在**没有交材料的入口** —— 今天摘掉这两颗键，产品就再也没法把一份
  转写喂进来，面板会永远空着。这是一笔有名字的账：建 `/sec` 交材料入口那一相，
  负责把它们摘掉。
- **面板的对话框接 `/api/chat` 时必须带 `readOnly: true`。** 不带的话
  `talkGate` 会打开议事对话 v2 的四个工具 —— 能往议题台账写证据、写候选判断、
  真出网搜一次。锁屏上一个输入框不该有这些。本体上下文在 `readOnly` 下仍然保留。
- **假模型那条「我来」正则只能匹配用户消息，不能匹配 system+user。**
  相三正是要把「我来做 X」写进 A7 的系统提示词 —— 一旦匹配拼接串，
  离线跑的每一条待办都会变成一号位的。
