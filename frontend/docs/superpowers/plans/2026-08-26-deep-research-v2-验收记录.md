## §5.1 九个必出现内容点

**内容点那一列要照任务书 §5.1 逐条抄进来，不要凭记忆写。** 抄错一个字，这张表就从「验收
标准」变成了「对一份转述的验收」，而那时候填「出现了」这三个字什么也不保证。

「缺失时定位到哪个节点」那一列填七个节点里的一个（N0 锚定主体 / N1 先验草稿 / N2 命题与检索
计划 / N3 分维度取证 / N4 校验合并 / N5 分层成稿 / N6 出口对账）—— 定位到节点是这张表的
全部意义：**缺了就去改那个节点的指令或那道门，不要在报告上补一段**。判断落在哪个节点，
`doc.sourceText` 文首那份「本轮机检未过的部分」和 trace 里每个节点自己那条记录是现成的线索。
